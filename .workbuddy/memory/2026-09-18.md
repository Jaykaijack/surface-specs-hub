### 关键问题与修复（重要经验）
1. **线上云数据不加载（核心坑）**：原先 SDK 走 `cdn.jsdelivr.net`，在浏览器环境实测 `ERR_CONNECTION_RESET`，导致 `WorkBuddyCloud` 未定义，`dataSource` 回退 `local`。**Node 侧同 URL 却返回 200**，说明 CDN 可达性不可依赖。→ 改为**优先加载仓库内自托管副本**，CDN 仅作兜底；并把 SDK 落到 `js/vendor/`。修复后线上 `dataSource === 'cloud'`。
2. **自检脚本误判**：`SurfaceCloud` 的回退原因写在 `fallbackReason`（不是 `lastError`）；且 `dataSource` 初始值就是 `'local'`，用 `waitForFunction(dataSource)` 会在云数据返回前提前通过，造成"看似回退"的假象。→ 诊断脚本改为读取 `fallbackReason` 并固定等待时长。
3. **补齐 favicon**：站点未声明 `link[rel=icon]`，浏览器请求 `/favicon.ico` 产生 404。→ 用内联 SVG data URI 图标（不新增文件、零外部请求），并补 `og:image`。
4. `agent-browser` CLI 在本机执行会异常中断（PowerShell/Bash 均复现）；Bash 环境运行时也缺 `ls/grep/head` 等命令。→ 验证改用 **Node 直接驱动 `playwright-core`**（复用 `agent-browser/node_modules/playwright-core` + 本机 `ms-playwright/chromium-1208`），输出稳定可靠。
