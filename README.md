### 2. 专业横向多机滚动比对工作台
- **Shift + 滚轮横向平滑漫游**：参数表超宽时无需手动拖拽滚动条，按住 Shift 滑动滚轮（或触控板左右双指滑行）即可顺畅漫游。
- **双轴粘性吸附（Dual-Axis Sticky）**：首列参数名称始终吸附锁定在屏幕左侧，顶部机型信息始终贴合在导航栏下方，横向比对数十项参数标签永不丢失。
- **差异智能高亮（Highlight Differences）**：一键开启高亮模式，当多机型参数存在代际差异时，自动渲染柔光标识。
- **仅看差异模式（Diff Only）**：一键过滤剔除所有数值相同的常规行，只展示选购决策分水岭，带货与选型培训极度高效。
- **全系跨品类自由混比**：打破产品线壁垒，支持把 Surface Pro 12 与 Surface Laptop 8、Laptop Studio 2 等不同形态的机型同时加入底部托盘（最多 5 款）同屏横向 PK。

### 3. 三大 Surface 专属深度分析工具
1. **3:2 黄金生产力屏幕比例与面积交互计算器**：
   - 动态调整屏幕尺寸（10.5" ~ 28.0"）；
   - 实时计算 Surface 3:2 相比传统 16:9 / 16:10 宽屏多出的物理有效显示面积（+18%）与纵向可视高度；
   - 真实比例线框双层重叠可视化，直观讲透“为什么办公选 3:2 不选大黑边带鱼屏”。
2. **微软定制芯片与 NPU AI 算力天梯榜 (TOPS)**：
   - 全面收录高通 Snapdragon X2 Elite (80 TOPS)、Snapdragon X Elite / Plus (45 TOPS)、微软 SQ1/SQ2/SQ3、Intel Core Ultra（第 2 代与第 3 代）及 AMD 定制芯片；
   - 标明微软官方 **Copilot+ PC 40 TOPS 准入红线**，清晰掌握端侧大模型算力阶梯。
3. **键盘盖与超感触控笔代际兼容全景矩阵**：
   - 一站式厘清 Surface Flex 蓝牙分离键盘、特制专业键盘盖、旧款 Type Cover、Slim Pen 2 触觉纸感震动在各代机型上的物理与电气兼容性，彻底杜绝主播讲错配件。

## 🚀 运行与分发指南

本工程为 **100% 纯前端静态架构**，**零外部网络依赖、零服务端依赖、零 Node/NPM 运行时需求**。

### 1. 本地直接双击运行（最便捷）
- 打开项目文件夹，直接双击运行 `index.html` 或 `surface-specs-hub-standalone.html`；
- 即可在任何现代浏览器（Microsoft Edge, Chrome, Safari, Firefox 等）中秒开，支持在无网络信号的机房、展台平板或演播室大屏离线演示。

### 2. 独立单文件封装发布版（可直接微信/钉钉传送）
- 根目录的 `surface-specs-hub-standalone.html`（或 `releases/` 目录下的版本快照）已将全量 CSS、JS 以及 **364 张高清真机图全部转为 WebP Base64 内嵌**；
- 单一文件体积约 21 MB，可直接作为离线文件分发给主播、客服与学员，随时随地双击即可查阅。

### 3. 部署到公网或内网 Web 服务器
将本工程静态资源推送到任何 Web 服务器（Nginx、Apache、Caddy 或静态托管服务），绑定域名即可上线：
```nginx
server {
    listen 80;
    server_name surface.kaibase.cn;
    root /var/www/surface-specs-hub;
    index index.html;
}
```
