# Surface 参数中心

微软中国来源优先的 Surface / Xbox 参数、配置比较与兼容查询。海外和历史规格保留地区及配置条件，待核实内容不会作为确定事实参与评分。

本地预览：`python3 -m http.server 8766`。验证：`node tests/test-runner.js`、`node tests/public-regression.test.js`。生成站点和独立离线 HTML：`node scripts/deploy/build-site.js`（Node.js、Python 3、Pillow）。构建输出位于 dist/ 和 releases/，不提交生成文件。

公开来源摘要见 docs/sources/；摘要和测试通过不代表全库真实性认证。测试及边界见 docs/testing.md。
