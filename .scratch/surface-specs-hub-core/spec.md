# Feature Spec: Surface Specs Hub Core

Pure-reproduction of HubWeb.cn tailored for the complete Microsoft Surface hardware family (2012-2026).

## Scope
1. 8 core product series, 46 historical and current models (fully decoupled commercial and consumer lines).
2. Dual-axis sticky horizontal comparison table with difference highlighting.
3. Three deep analytical tools: 3:2 screen calculator, processor/NPU ladder, bidirectional accessories matrix.
4. Official high-resolution product imagery with interactive color switching (strictly authentic commercial colors).
5. 100% offline single-page architecture with zero server dependencies.
