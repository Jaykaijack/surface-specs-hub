# 离线发布版本一致性修复

发布脚本原先在上传 `dist/site` 后再单独上传根目录离线 HTML，该稳定指针可能比实际源码旧。现在离线包在构建时成为 `dist/site/surface-specs-hub-standalone.html` 的正式产物，随站点同包上传，远程脚本不再读取根目录旧指针。

构建自动遍历不可变快照，校验内嵌来源记录与当前入口、CSS、JS、数据及证据文件哈希。旧快照缺元信息或任一输入不一致均不可复用。还对照快照提交检查嵌入原图和打包器有无变化；存在未跟踪图片时不允许沿用旧包。没有匹配快照则使用既有 Python 离线构建器生成新快照，生成后再次校验，失败即停止。

不依赖某个日期文件名。仅发布脚本/说明变化时，快照提交可早于发布提交，但所有运行时输入必须完全一致；`build-info.json` 分别记录 snapshotGitSha、publishingGitSha、输入哈希和离线包 SHA-256。当前经浏览器验证的 2a08187 快照会被自动选中。

新回归检查旧包/缺失元信息被拒绝，以及 JS、数据、CSS、证据变化使旧包失效。加入站点构建前门禁。构建引用检查忽略内联 JS 中的 HTML 模板字符串，但保留实际 script src 检查；离线运行由浏览器进一步验证。

本次没有运行 SSH/SCP，没有修改系统层或恢复凭据，生产部署仍等待原有连接恢复。

验证：主测试4987项通过、0失败；独立审查/字段审查/证据分包/新增离线发布回归及五项预检通过；站点构建通过，本地HTTP冒烟19/19通过。对正式产物 `dist/site/surface-specs-hub-standalone.html` 的浏览器验证通过：全部1131项结论、源码/证据哈希、Ultra参数、1220g计算、窄屏和合并样式，零额外资源请求、零页面异常。正式离线产物SHA与build-info一致。未进行云环境部署；原部署Mac可拉取最终main后按既有流程发布。
