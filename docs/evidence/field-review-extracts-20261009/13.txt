L155: ## Surface Pro X and Windows 11
L156: 
L157: The Surface Pro X has a custom Microsoft SQ1™ or Microsoft SQ2™ ARM processor. Your Surface comes with:
L158: 
L159:   * Windows 11 Home for ARM-based PCs (consumer customers)
L160:   * Windows 11 Pro for ARM-based PCs (commercial customers)
L161: 
L162: If you have questions about how the ARM processor works, go to cite78†Windows on ARM-based PCs FAQ .
L163: If you have Windows 11 Home on your device, you can upgrade to Windows 11 Pro for an additional cost. For more info, see cite79†Upgrade Windows 11 Home to Windows 11 Pro .
L164: 
L165: Not sure which version of Windows you have? See cite80†Which Windows operating system am I running? L166: 
L167: Note
L168:

L174: ## Surface Pro X features
L175: ### Get more done with an edge-to-edge display
L176: 
L177: Surface Pro X has a 13" PixelSense® touchscreen display with 2880x1920 resolution for your images, videos, and calls. Use Eye Contact to adjust your gaze on video calls and connect with your audience.
L178: You can find the Eye contact setting by selecting Start cite83†Image: icon for Windows logo icon > Settings cite84†Image: icon for Settings app icon > Bluetooth & devices cite85†Image: icon for Bluetooth icon > Cameras cite86†Image: icon for Camera icon > Surface Camera Front, and then looking under Camera Effects.
L179: 
L180: Open Camera Settings
L181: ### Connect nearly anywhere, any time
L182: 
L183: When you're ready to use Surface Pro X, it turns on quickly and gets you signed in fast with Windows Hello. Get online no matter where you are with optional built-in LTE.
L184: 
L185: ### Ready when creativity strikes
L186: 
L187: Capture every idea with a Surface Slim Pen. When you’re done, store and charge it in the Surface Pro X Signature Keyboard. To use more accessories, use the two USB-C ports to connect to displays, docking stations, and more.
L188: ### Built for how you live and work
L189: 
L190: Surface Pro X was designed for fast performance and you can choose between Microsoft SQ1™and SQ2™processors. Run your web apps in Microsoft Edge or get more apps from the Microsoft Store. For info on what apps can run on your Surface Pro X, go to cite78†Windows on ARM-based PCs FAQ .

Testing conducted by Microsoft in August 2021 using preproduction software and preproduction Surface Pro X with Microsoft SQ® 1 and Surface Pro X with Microsoft SQ® 2, 256GB, 8GB RAM devices. Testing consisted of full battery discharge with a mixture of active use and modern standby.
L284: The active use portion consists of (1) a web browsing test accessing 8 popular websites over multiple open tabs, (2) a productivity test utilizing Microsoft Word, PowerPoint, Excel and Outlook, and (3) a portion of time with the device in use with idle applications. Tested with Windows Version 11.0.22000.9 (21H2). All settings were default except screen brightness was set to 150 nits with Auto-Brightness disabled. Wi-Fi was connected to a network.

Testing consisted of full battery discharge with a mixture of active use and modern standby.
