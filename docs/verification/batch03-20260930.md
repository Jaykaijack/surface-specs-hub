# Batch03 历史型号图片与来源核验

核验日期：2026-09-30。范围：Surface Pro 初代、Surface Pro 2、Surface Pro 7+、Surface Go 3 商用版，以及 Pro 初代/Pro 2 的部分字段。

## 已确认来源

- Pro 初代：微软中国官方 Support 页面明确列出 Windows 8 专业版、720p 前后摄像头、42 Wh 电池、VaporMg 和立体声扬声器。
- Pro 2：微软中国官方 Support 页面明确列出 Windows 8.1 专业版、720p 前后摄像头、Dolby 立体声扬声器、VaporMg 和结构图。
- Pro 7+：微软中国官方 Support 页面提供型号标题、结构图和完整技术规格。抓取的图片是硬件标注结构图，不是颜色照片。
- Go 3：微软中国官方 Support 页面提供型号标题、结构图，并明确 USB-C、Surface Connect、耳机/麦克风插孔、商用 Windows 版本等信息。抓取的图片不是颜色照片。

## 图片结论

此前 Pro 1/Pro 2 复用了现代 Pro 黑色像素图；Pro 7+ 和 Go 3 商用版把同一个文件绑定到两个颜色。现已撤下这些不可靠的配色映射。

| 型号 | 当前图片 | 结论 |
| --- | --- | --- |
| Pro 初代 | Pro 2 官方结构图 | `shared`，其他机型结构图示意，不是 Pro 初代配色照片 |
| Pro 2 | Pro 2 官方结构图 | `diagram`，型号可确认，颜色不可确认 |
| Pro 7+ | Pro 7+ 官方结构图 | `diagram`，型号可确认，颜色不可确认 |
| Go 3 商用版 | Go 3 官方结构图 | `diagram`，系列型号可确认，商用双色照片不可确认 |

结构图文件位于 `assets/products/`，图片来源与 SHA256 记录在 `releases/verification-20260930-batch03/image-source-ledger.json`。颜色字段的图片路径现在为 `null`，界面显示“官方结构图（非配色照片）”或“其他机型结构图示意”，不能再把结构图冒充颜色照片。

Pro 初代官方博客中的大图链接在 2026-09-30 返回 HTTP 404，因此没有下载不存在的文件。链接和失败状态保存在图片来源账中。
