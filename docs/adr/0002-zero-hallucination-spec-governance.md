# ADR-0002: 建立零脑补数据治理机制（Zero-Hallucination Policy）

## 状态
已采纳 (Accepted) - 2026-09-16

## 上下文
在以往参数整理中，由于部分官方白皮书（如某些商用机型或早期机型）未公布具体电池瓦时、摄像头光圈或散热功率，AI 模型容易产生幻觉胡编数字（如臆测电池 mAh、乱编重量）。
这在面向主播培训与严肃业务场景中存在极高的误导合规风险。

## 决策
1. **严格禁止主观脑补**：任何未见于官方权威文档的参数，严禁推测或编造。
2. **四态参数值规范**：
   - `VALID`：经官方验证的确凿参数值（如 `2880 × 1920`, `Snapdragon® X2 Elite`）。
   - `NOT_DISCLOSED`：官方技术白皮书确未公开，明确标注为 `<span class="spec-state not-disclosed">官方未披露</span>`。
   - `NOT_APPLICABLE`：产品形态物理上不存在该功能，明确标注为 `<span class="spec-state not-applicable">不适用</span>`（如折叠双屏无键盘盖接口、纯笔记本不适用笔震动）。
   - `NULL`：数据缺省，展示为标准缺省符 `—`。
3. **四级数据源权重阶梯**：
   - 第一级（权威基石）：微软官方技术白皮书 (Microsoft Learn)、Surface IT Pro 部署指南。
   - 第二级（官方口径）：微软官方商城产品技术规格页 (microsoftstore.com.cn)。
   - 第三级（官方认证）：工信部入网许可、3C 认证、FCC 申报白皮书。
   - 第四级（工程实测）：权威硬件拆解实测（如 iFixit 电池拆解容量，需显著标注来源）。

## 后果
- **优势**：
  - 彻底规避直播间虚假宣传与参数失实风险。
  - 数据中心树立严肃、严谨的专业技术权威形象。
- **代价**：
  - 部分历史早期参数会显示“官方未披露”，但这种实事求是的标注比编造数据更能赢得专业用户信赖。
