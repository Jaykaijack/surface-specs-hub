# ADR-0005: 移除可选云端叠层（素材中心 / 成员登录）

## 状态

已采纳 (Accepted) - 2026-09-22

取代 ADR-0001「修订（2026-09-22）」中允许可选云端叠层的条款。

## 上下文

ADR-0001 的修订条款曾允许一个**可选云端叠层**，用于资产库与数据同步，条件是默认关闭、
不得成为核心规格数据的真源。该层随后被实现为 5 个文件：

| 文件 | 体积 |
|---|---|
| `js/vendor/workbuddy-cloud-sdk.global.js` | 59 KB |
| `js/cloud-ui.js` | 43 KB |
| `js/cloud-client.js` | 21 KB |
| `css/cloud.css` | 10 KB |
| `js/cloud-config.js` | 0.5 KB |

实际投入使用后确认：

1. **业务上不需要。** 该层提供的两项能力——"成员登录/账号"与"云端素材中心"——不属于本项目的
   使用场景。本项目是面向直播团队与销售顾问的**离线参数查阅工具**，不含协作与素材共享需求。
2. **关闭开关无法隐藏界面入口。** `js/cloud-config.js` 虽为 `enabled: false`（数据层确实不发任何
   网络请求），但顶栏的「素材中心」按钮**硬编码在 `index.html` 中**，「成员登录」按钮由
   `cloud-ui.js` 在运行时注入。结果是界面上长期存在两个点击后只能看到「需要登录」或
   「云端未激活」的死入口。
3. **它违背了 ADR-0001 的零依赖目标。** 该层引入了唯一的 vendored 第三方运行时
   （`workbuddy-cloud-sdk.global.js`），而核心规格数据始终来自随包内置的 `js/surface-data.js`。

## 决策

彻底移除该可选云端叠层，不做保留或条件编译。

1. 删除上述 5 个文件（含 `js/vendor/` 整个目录，该目录下仅有云端 SDK 一个文件）。
2. 删除 `scripts/cloud-migration/`（`build-payload.js` / `measure.js` / `verify-payload.js`）——
   这三个脚本是当年向云端写入数据集的配套工具，随云端层一并失去用途。
3. 清理 9 处引用：`index.html`（样式、脚本、顶栏按钮、账号入口占位）、
   `js/app.js`（`#/assets` 路由、`renderAssetsView`、云端初始化与数据集静默同步）、
   `css/hubweb-layout.css`（`.cloud-account-btn` 孤立样式规则）。
4. 撤销 `#/assets` 路由。该路由唯一入口是顶栏按钮，无外部深链接依赖。

## 保留项（有意为之）

`js/catalog.js` 的 `Catalog.acceptsCloudVersion(version)` **保留**。

它是一个纯字符串比较函数，用于防止过期的云端数据集覆盖本地核验基线。它不含网络请求、不含 UI、
不含任何外部依赖，且不属于被移除的"素材中心/成员登录"功能范畴。移除它会连带改动
`tests/test-runner.js` 中 4 条断言，属于无收益的改动扩散。

代价：该函数目前**无调用方**（云端数据源已不存在），是一段备用门禁。若将来重建云端数据通道，
它是必需的准入校验。

## 后果

**优势**

- 界面不再存在"点了没反应"的死入口。
- 运行包减少 5 个文件、约 136 KB、约 2600 行代码。
- 移除了唯一的 vendored 第三方运行时，项目回归 ADR-0001 定义的完全零依赖形态。
- 任何访问者在任何域名下都不会再看到与登录相关的界面元素。

**代价**

- 将来若需要云端协作能力，须按 git 历史恢复（全部文件均在版本库中，可完整找回）并重新登记
  云服务资源 Origin。
- 与之关联的云服务资源 `wbcs_h1FTF67Q21WxgD2zj5QEVU` 已无用途（其绑定的旧域名亦已于
  2026-09-22 下线），可在控制台清理。

**不受影响**

核心规格数据的真源始终是随包内置的 `js/surface-data.js`，与本次移除无关。规格查阅、双轴对比、
计算工具、数据核验等全部核心能力零影响。
