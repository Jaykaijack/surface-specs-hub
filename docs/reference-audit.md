# HubWeb (Apple 参数中心) 逆向工程与设计审计报告 (Reference Audit)

## 1. 调研背景与审计对象

- **审计目标**：深入解构专业数码规格参数平台 [HubWeb.cn](https://hubweb.cn/) 的产品架构、视觉系统与交互体验，为构建生产级「Microsoft Surface 产品参数中心」提供精准对齐与差异化升华参考。
- **审计范围**：
  - 首页及分类组织架构 (`index.php`, `index_menu.php`, `index_main.php`)
  - 核心多代产品横向对比表格页 (以 MacBook Pro、iPad Pro 为代表)
  - 芯片规格与天梯体系 (Apple Silicon A/M 系列)
  - 响应式视口适配：1920px 宽屏、1440px 笔记本、iPad 平板端、390px 移动端

---

## 2. HubWeb 页面与信息架构拆解

### 2.1 整体布局骨架 (Layout Anatomy)
- **桌面端 (1440px / 1920px)**：
  - **三段式结构**：
    1. **顶部栏 (Header, 40px ~ 48px)**：常驻 Logo、站点标题、社交外链及全屏切换，高度紧凑，极低垂直空间占用；
    2. **左侧固定菜单 (Sidebar, 150px ~ 220px)**：以产品大类（Apple Silicon、Mac、iPad、Watch、AirPods、iPhone、报告工具）建立树状折叠手风琴结构；
    3. **主工作台 (Main Area)**：右侧剩余全部宽度，内部按需横向横向溢出滚动，无整体页面横向滚动条。
- **移动端 (390px / iPad)**：
  - 左侧边栏折叠为汉堡抽屉或顶部横向滑动 Tab；
  - 表格首列固定，右侧多列机型在屏幕视口内水平滑行。

### 2.2 核心横向对比大表 (Horizontal Spec Table) 关键技术特征
- **信息密度极高**：单元格内边距紧凑（约 8px ~ 12px），字号在 12px ~ 14px 之间，单屏可呈现大量参数，拒绝过度留白造成的效率浪费。
- **双轴粘性吸附 (Dual-Axis Sticky)**：
  - **垂直滚动时**：机型名称、缩略图、发布年份的表头贴合固定在 Header 下方；
  - **水平滚动时**：最左侧的“参数名列”通过 `position: sticky; left: 0` 保持锁定，用户横向滚至数十代机型时，参数标签永不丢失。
- **滚动辅助交互**：
  - 界面明示：“`tip: shift + 鼠标滚轮 = 横向滚动`”，配合现代触控板的双指左右横滑，交互体验极其顺畅；
  - 杜绝页面外层 Body 发生横向晃动（`overflow-x: hidden` 于外部，`overflow-x: auto` 于表格容器）。
- **参数分组机制**：
  - 按“基础”、“性能”、“显示屏”、“摄像头”、“连接”、“电源”、“音频”等大类设立分组行（带背景底色与折叠开关），有效降低长表格认知负荷。

## 3. 视觉系统与排版规范

| 维度 | HubWeb 表现 | Surface Product Hub 继承与改进方案 |
| :--- | :--- | :--- |
| **主调色盘** | 浅灰底 `#F5F5F5`、深色模式 `rgb(29, 29, 29)`、黑灰文字 | **升级为微软 Fluent 2 官方色盘**：Mica 亚克力底色、Windows 11 灰白阶梯、微量微软蓝 (`#0078D4`) 交互强调。 |
| **字体族** | SF Pro, PingFang SC, Helvetica Neue (Apple 风格) | **规范采用微软官方字体族**：Segoe UI Variable Text, Segoe UI, Cascadia Code 配合微软雅黑。 |
| **卡片与边框** | 1px 浅灰色细实线、几乎无阴影或超轻投影、圆角 4px~8px | **保留极简细线**：`border: 1px solid var(--ms-border-subtle)`，辅以 Fluent 2 层级阴影。 |
| **深色模式** | 纯粹反色与灰黑切换 | **真正专业 Dark Mode**：针对表格斑马纹、高亮色块、SVG 轮廓与文本对比度定制调校（WCAG 2.2 AA 标准）。 |
| **状态呈现** | 文本或简易 Badge | **状态标签增强**：区别国行在售 (`current_cn`)、停售、海外版，直观高对比度徽标。 |

## 4. 借鉴价值 vs. 严格禁忌（不应照搬点）

### ✅ 应当完全借鉴与发扬的优秀机制
1. **参数优先与极致信息密度**：拒绝电商花哨促销大图，首屏直奔规格参数与横向对比。
2. **多机型横向横滚比对机制**：左侧粘性参数名 + 顶部粘性机型卡 + Shift 滚轮联动。
3. **差异高亮与仅看差异过滤**：快速隐藏全机型相同的配置行，仅展现核心代际代差。
4. **芯片与特色工具生态库**：不仅有整机，还有独立处理器参数库与专项可视化工具。

### ❌ 严格禁止照搬与 Surface 化的调整重点
1. **禁止直接套用 Apple 专属参数维度**：
   - 苹果关注的：雷电/USB接口版本、蜂窝版基带芯片型号、激光雷达 LiDAR、原彩显示、ProMotion；
   - **Surface 专属核心维度**：**NPU TOPS 算力**、**Copilot+ PC 认证**、**3:2 黄金生产力比例**、**PixelSense 触控**、**可拆卸 SSD 快拆门**、**零重力/动态支点铰链**、**Surface Flex / 签名版键盘盖与 Slim Pen 2 触觉纸感震动**。
2. **禁止假数据与脑补推断**：
   - 绝不允许为了填满表格而自行猜测电池 Wh 或未公布数据；
   - 必须实现 `null`（—）、`not_disclosed`（官方未披露）、`not_applicable`（不适用）三级精准标注。
3. **禁止将复杂 SKU 扁平混淆**：
   - 必须通过 `Product + Variant` 模型支持同代产品的 Intel / Snapdragon 平台、13.8" / 15" 屏幕尺寸细分。
