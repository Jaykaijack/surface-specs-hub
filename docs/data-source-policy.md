# Surface 参数数据可信度与来源溯源政策 (Data Source & Unknown Spec Policy)

## 1. 零臆测原则 (Zero-Hallucination Policy)

作为面向业务培训与技术决策的专业级产品参数数据库，**数据的绝对真实可信度压倒一切**。

- **严禁 AI 自动脑补推算**：绝对禁止在无官方权威白皮书或认证数据的情况下，自行填补或猜测参数；
- **严禁偷换概念**：例如微软官方未标明早期机型电池额定 Wh 时，不可随意抓取民间第三方未经核实的容量数值冒充官方标准。

---

## 2. 字段状态规范与界面呈现规则 (Spec Value States)

所有规格字段必须严格处理缺失与不适用场景，系统定义 4 种字段取值状态：

| 状态类型 | 业务定义 | 界面统一显示样式 | 适用示例 |
| :--- | :--- | :--- | :--- |
| `VALID` | 官方或权威核实的数据已明确确认 | 显示实际参数值与单位（如 `58.0 Wh`） | 官方规格表明确列出项目 |
| `NOT_DISCLOSED` | 该指标客观存在，但微软官方白皮书从未对外正式披露 | **`官方未披露`** (灰色弱化标示) | 早期部分高通芯片具体 TFLOPS、部分电池额定容量 |
| `NOT_APPLICABLE` | 该产品由于形态物理特性完全不具备该属性 | **`不适用`** (次级灰色文本) | 传统笔记本 Laptop 的手写笔压感、台式一体机 Studio 的电池容量 |
| `NULL / UNKNOWN` | 暂时缺少该项资料或尚未完成核验 | **`—`** (标准短破折号) | 早期停售机型的细碎备件号 |

---

## 3. 数据来源分级与权重矩阵 (Source Hierarchy)

每项关键参数支持溯源，来源权威级别由高到低严格排布：

1. **第 1 优先级 · Microsoft 官方产品页与技术白皮书 (microsoft_official)**：
   - 微软官方商城规格标签、发布会 Keynote 官方技术白皮书、FY27 官方技术工具包；
2. **第 2 优先级 · Microsoft 官方技术支持库 (microsoft_support)**：
   - `support.microsoft.com` 发布的详细规格说明书、配件代际兼容性支持清单；
3. **第 3 优先级 · Microsoft 官方技术文档 (microsoft_learn / datasheet)**：
   - 面向企业 IT 管理员的 Surface 硬件工程文档、Secured-core PC 安全架构说明；
4. **第 4 优先级 · 权威第三方实验室核验 (third_party_verified)**：
   - 仅限于 iFixit 拆解可维修性报告、FCC 认证射频与电池文件。
   - **合规强制要求**：凡引用第三方数据，系统必须标注“*非微软官方公开数据，源自权威实验室实测*”。

---

## 4. 来源冲突与人工核验机制 (Conflict Resolution)

当不同官方文档之间出现参数口径不一致时（如：全高清视频播放续航 20 小时 vs 微软标准日常综合办公续航 15 小时）：
1. **不进行单一覆盖**：字段细分为 `batteryLifeOffice` (日常办公) 与 `batteryLifeVideo` (本地视频)；
2. **多口径注明**：在单元格说明中同时列出不同测试工况的官方说明，保证全面严谨。
